PROJECT 01 · STATISTICAL SOFTWARE

Multidimensional Poverty Index Tool

A Python and Streamlit application designed to support multidimensional poverty measurement using the Alkire-Foster methodology.

Python Streamlit Alkire-Foster Method Official Statistics

Project Overview

Poverty is multidimensional and cannot always be fully understood through income alone. This project focuses on developing a tool that helps users configure dimensions, indicators, deprivation rules and weights for multidimensional poverty analysis.

Objectives

  • Support configuration of MPI dimensions and indicators.
  • Allow users to define indicator deprivation rules.
  • Support data validation and dataset exploration.
  • Provide a structured workflow for MPI analysis.

Technology Stack

  • Python: Application logic and data processing.
  • Streamlit: Interactive web interface.
  • Pandas: Tabular data management.

Project Current Development Status

The application is being developed in stages, beginning with dataset loading, MPI configuration and indicator setup. Additional analysis and reporting features can be documented as they are completed and tested.
