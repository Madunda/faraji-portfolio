PROJECT 03 · STATISTICAL COMPUTING

Statistical Analysis with R

Applying R programming to data preparation, exploratory data analysis, statistical estimation and data visualisation.

R Programming Data Cleaning Statistics Visualisation

Project Overview

Statistical analysis transforms raw data into meaningful information for research, planning and decision-making. This project focuses on using R to prepare datasets, examine data quality, calculate statistical summaries and communicate findings through tables and charts.

Project Objectives

  • Import and inspect datasets from Excel, CSV and Stata files.
  • Identify missing values, duplicates and inconsistent data.
  • Perform exploratory data analysis (EDA).
  • Summarise categorical and numerical variables.
  • Calculate weighted proportions and descriptive statistics.
  • Create charts and visualisations for reporting.

Analysis Components

1. Data Preparation

Organise variables, check data types, identify missing observations and prepare datasets for analysis.

2. Exploratory Data Analysis

Explore distributions, frequencies, summary statistics and relationships between variables to understand the data before conducting further analysis.

3. Weighted Statistical Estimates

Apply survey weights where appropriate to estimate population-level proportions and other statistics, taking the survey design into account when required.

4. Data Visualisation

Present analytical findings using informative charts, tables and graphical summaries.

Technology Stack

  • R: Statistical programming and analysis.
  • tidyverse: Data manipulation and workflows.
  • ggplot2: Data visualisation.
  • readxl: Importing Excel data.
  • haven: Working with Stata and other statistical files.

Development Status

This portfolio project describes an analytical workflow for working with statistical data in R. Specific datasets, results and visualisations can be added as completed analyses are selected for publication.
